# JSON Verisi İnceleme ve Tarayıcı Network Ekranı

## HTTP/API Notlarım

- **Network Sekmesi:** İstekleri (XHR/Fetch), durum kodlarını (200, 404, 500 vb.) ve yanıt sürelerini incelemek için kullanılır.
- **Headers:** İstek (Request) ve yanıt (Response) başlıklarını, Content-Type ve yetkilendirme bilgilerini gösterir.
- **JSON Verisi:** API yanıtlarının yapısını (key: value, dizi ve nesneleri) okumak ve alan adlarını doğrulamak için kontrol edilir.
